CapitalSync

Consulta e comparação de ativos com backend ASP.NET Core e integração com provedores externos.

C#.NETRESTRailway
Browser → ASP.NET Core API → Market Provider → Cache → Response
Live ↗GitHub ↗
Problema

Centralizar consulta de ativos sem acoplar a interface diretamente ao provedor de mercado.

Decisão

API intermediária em .NET, tratamento de falhas externas e cache para reduzir chamadas repetidas.

Evolução

Ampliar testes, observabilidade e independência entre provedores.

AtmosIQ

Aplicação climática moderna com React/TypeScript e separação clara de estado, dados e UI.

ReactTypeScriptViteQuery
UI → TanStack Query → Weather API → Zustand → Components
Live ↗GitHub ↗
Problema

Organizar dados meteorológicos assíncronos sem espalhar estado e requisições pela interface.

Decisão

React + TypeScript com camada de fetching/cache e estado de aplicação separados.

Evolução

Mais testes de componentes, acessibilidade e cenários de erro de rede.

MS Barbearia

Sistema de operação em PHP/MySQL com área do cliente e painel administrativo para agenda, preços, presença e receita.

PHPMySQLAdminRailway
Cliente/Admin → PHP/PDO → MySQL → Railway
Live ↗GitHub ↗
Problema

Centralizar reservas e a operação diária da barbearia sem depender de controles paralelos de agenda e preço.

Decisão

MySQL como fonte de verdade, slot único no banco, painel admin separado, CSRF e snapshot do preço em cada reserva.

Evolução

Relatórios mensais, lembretes automáticos e testes de integração com banco isolado.

SmartGate Arduino

Cancela bidirecional com sensores ultrassônicos, servo, sinalização e proteção durante o fechamento.

ArduinoC++HC-SR04Servo
Sensor A/B → State Machine → Arduino → Servo + LED + Buzzer
GitHub ↗
Problema

Identificar o sentido de passagem e evitar fechar a barreira enquanto existe obstáculo detectado.

Decisão

Dois sensores e máquina de estados simples para distinguir A→B e B→A.

Evolução

Substituir delays por millis(), filtrar leituras e adicionar fins de curso.
