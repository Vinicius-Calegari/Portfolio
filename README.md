# Portfólio — Vinícius Calegari

Portfólio pessoal focado em desenvolvimento full stack, APIs, dados, automação e sistemas embarcados.

## Online

- Portfólio: https://viniciuscalegari.netlify.app
- Case técnico MS Barbearia: https://viniciuscalegari.netlify.app/ms-barbearia.html

## Projetos em destaque

### CapitalSync
ASP.NET Core, APIs de mercado, cache, testes, CI e deploy no Railway.

### AtmosIQ
React + TypeScript com separação entre UI, estado e acesso a dados.

### MS Barbearia
Sistema PHP/MySQL publicado no Railway com:

- área do cliente;
- agendamento com bloqueio de concorrência;
- painel administrativo;
- preços editáveis;
- preço histórico por reserva;
- controle de comparecimento e faltas;
- receita prevista e realizada;
- CSRF e sessão segura;
- migrations e CI.

### SmartGate Arduino
Protótipo embarcado com sensores ultrassônicos, servo e máquina de estados.
