MS Barbearia

Sistema de operação de uma barbearia desenvolvido em PHP e MySQL. O projeto evoluiu de um agendamento simples para uma aplicação com área do cliente, painel administrativo, preços dinâmicos, registro de presença/falta, métricas financeiras e deploy automatizado no Railway.

Abrir sistema ↗Ver código ↗
Problema

Organizar reservas, clientes, disponibilidade, preços e confirmação de atendimento sem depender de controles manuais dispersos.

Decisão

PHP + PDO com MySQL persistente, regras no servidor, sessões seguras, CSRF e painel administrativo separado.

Resultado

Aplicação publicada com CI, migrations, controle de concorrência de horários e gestão operacional pela própria interface.

Arquitetura

Do cliente ao banco.

Cliente → PHP + Sessão + CSRF → PDO → MySQL │ ├─ Área do cliente ├─ Catálogo e preços ├─ Agenda / disponibilidade └─ Painel administrativo Admin → confirmação → presença/falta → receita realizada GitHub → CI PHP → Railway → migration → FrankenPHP
Engenharia

O que existe além da interface.

Preços dinâmicos

O administrador altera valores no painel; novas reservas usam o preço vigente e reservas antigas preservam o valor histórico.

Concorrência

Restrição única no MySQL impede dois clientes de reservarem o mesmo horário, mesmo em requisições simultâneas.

Comparecimento

Após o horário, a equipe registra “compareceu” ou “faltou”, separando status da reserva de presença física.

Métricas

Dashboard diferencia receita prevista de receita realizada com base em atendimentos que realmente aconteceram.

Segurança

Prepared statements, password hashing, CSRF, sessões regeneradas e credenciais administrativas fora do repositório.

Deploy

Container com FrankenPHP, MySQL persistente, migration idempotente, healthcheck e CI de sintaxe PHP.
